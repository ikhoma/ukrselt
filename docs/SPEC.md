## 0. Обсяг

**Входить:** перенос 1:1 усіх опублікованих сторінок (uk), дизайн-токени, компоненти, анімації, форма, аналітика, SEO, хостинг на Vercel.

**Зміни відносно Framer (погоджено):**
- Форма: 2 поля і мікроанімація кнопки замість сторінки `/success`.
- Шрифт Inter прибираємо, усюди Open Sans.
- Картинки PNG → WebP.
- Виправлення помилок: латинська «C» у title і в «Cтоматолог-терапевт», «Розкад роботи», placeholder «urkselt», назви токенів і компонентів.
- `/team/*` і `/services` будуються з content collections (дані окремо від шаблону).
- Один `<h1>` на сторінку, alt для фото людей.

**Не входить (окремий етап після переносу):** 5 нових сторінок `/services/<slug>` і `llms.txt` за ТЗ маркетингу.

**Не переносимо:** чернетку `/price-2`, службову сторінку `Design`, `Examples.tsx`, бібліотеки `Framer University` і `Framer`.

## 4. Анімації

Параметри виносимо в `src/scripts/animations.ts`. Реалізація: CSS для простих появ, GSAP + ScrollTrigger для скролу.

### 4.1 Прелоадер
Готовий `logo-preloader.svg` (SMIL, без JS): синій хрест, маска 40×40, 1 с, easing `0.5 0 0 1`. **TBD:** тривалість показу і умова зникнення (від неї залежить затримка 2 с у §4.2).

### 4.2 Поява при завантаженні (головна, після прелоадера)
Початок: opacity 0.001. Затримка 2 с.
- spring, bounce 0.2, duration 0.5 s
- spring, bounce 0.2, duration 0.3 s
- spring, stiffness 400, damping 30, mass 1 (затримка 2 с; є варіант із затримкою 1 с)
- tween 0.5 s, ease `[0.44, 0, 0.56, 1]`
- підйом по y: 120px (≥1200), 72px (≤1199)

### 4.3 Hero: ротатор слів
H1 «Змінюємо» + слова, що по черзі виїжджають з-під маски: «усмішки.», «життя.».
- Для SEO і скрінрідерів: один `<h1>` з повною фразою. **TBD:** точний текст фрази.
- Анімований ротатор: окремий блок з `aria-hidden="true"`, маска `overflow: hidden`.
- **TBD:** тривалість, пауза, easing, цикл; зняти з компонента `text-loop` у Framer.

### 4.4 Поява при скролі
Fade-in, поріг видимості 0.5 (`__framer__threshold`). Transition: tween 0.2 s, ease `[0.5, 0, 0.88, 0.77]`, і миттєвий варіант (0 s, `[0.12, 0.23, 0.5, 1]`). Застосування по секціях зняти при реалізації.

### 4.5 Паралакс
Швидкості 110, 90, 95 (Framer `speed`). Блоки з круглими фото, що «пливуть». Один компонент, GSAP ScrollTrigger (scrub).

### 4.6 Скрол-трансформації (AnimationTimeline: Services і Team на головній)
Тригери `onScroll` / `onScrollTarget`. Цілі трансформацій:
- opacity 0 → 1, rotate −90°, scale 0.5 → 8
- opacity 0 → 1, rotate −90°, scale 0 → 10
- opacity 0 → 1, scale 0.9 → 1

**Services:** окремий останній етап (§10, етап 9). Варіант A: 1:1. Варіант B: переробка, щоб показувати реальні послуги. Рішення приймає Іван перед етапом.
**Team:** робимо обовʼязково, 1:1 (етап 6). Картки беруться з колекції `team`, тому анімація має коректно працювати з іншою кількістю лікарів: нових лікарів додаємо окремим кроком без переробки анімації.

## 5. i18n

- Зараз: тільки `uk`. У Framer локалізація порожня (жодної додаткової локалі), `/en/*` повертає 404.
- **TBD (чекаємо клієнта):** чи потрібна EN і звідки тексти.
- Архітектура з запасом: Astro i18n, `defaultLocale: 'uk'`, `prefixDefaultLocale: false`. Українська лишається без префікса (URL не змінюються), EN за потреби з'явиться на `/en/...` разом з hreflang.
- Вимога: нову локаль додаємо без змін у компонентах. Для цього:
  - усі тексти інтерфейсу (меню, кнопки, форма, футер) винесені в словники `src/i18n/<locale>.json`;
  - контент колекцій (`team`, `services`) має поле локалі;
  - список локалей задається в одному місці конфігу; маршрути, hreflang, `<html lang>`, sitemap і перемикач мови будуються з нього автоматично.
- **Перемикач мови лишаємо** (на живому сайті є «Select Language», зараз з одним пунктом «Ukrainian»). Розташування й вигляд зняти з живого сайту при реалізації. Поки локаль одна, він показує тільки її; з додаванням EN список оновиться сам.
- `<html lang="uk">`.

# ADR-0001: Стек — Astro + CSS-змінні + GSAP

**Status:** Accepted (HANDOFF)
**Date:** 2026-10-30
**Deciders:** Іван

## Context
Сайт на Framer: 13 публічних сторінок, контент майже статичний, одна форма, анімації (появи, паралакс, скрол-трансформації, ротатор слів). Потрібні: швидкість на мобільних (весь рекламний трафік мобільний, LCP ≤ 2,5 с за ТЗ маркетингу), контроль SEO, незалежність від Framer.

## Decision
- **Astro** як генератор сторінок (zero-JS за замовчуванням, компонентна модель, content collections, вбудований i18n і оптимізація зображень).
- **CSS зі змінними** (токени з Framer), без Tailwind: дизайн уже має систему токенів, утиліти тільки додали б шар перекладу.
- **GSAP + ScrollTrigger** для скрол-анімацій. З 2025 року весь GSAP, включно з плагінами, безкоштовний для комерційного використання.
- **Без React/фреймворків островів.** Інтерактив (меню, форма, перемикач мови, ротатор) — нативні скрипти в Astro-компонентах.

## Options Considered
| | Astro (обрано) | Next.js | Лишитись на Framer |
|---|---|---|---|
| JS на клієнті | мінімум | React-рантайм на кожній сторінці | ~1 МБ рантайму Framer |
| Контроль SEO/розмітки | повний | повний | обмежений (14 H1 на головній, один title на всі сторінки) |
| Складність | низька | середня | найнижча |
| Вартість | хостинг Vercel | хостинг Vercel | підписка Framer |

## Consequences
- Легше: продуктивність, SEO, повний контроль розмітки, версіонування в git.
- Складніше: анімації Framer (пружини, appear-ефекти) треба відтворювати вручну (див. ADR-0005); правки контенту тепер через код (див. ADR-0003, відкрите питання).

## Risks
- Без React не можна напряму перевикористати code-компоненти Framer (`Map.tsx`, `Lottie.tsx`). Обидва замінюються: карта — iframe (ADR-0007), Lottie на живому сайті не знайдено.

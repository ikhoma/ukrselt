# ADR-0007: Сторонні скрипти — GTM, Hotjar, Google Maps

**Status:** Proposed
**Date:** 2026-10-30
**Deciders:** Іван

## Context
- GTM-W46JLBGN: тегами керує команда реклами; прибирання `/success` з ними погоджено.
- Hotjar 5188670: вшитий у код сайту, не в GTM.
- Google Maps embed на `/contacts` (iframe з параметром `pb`).

## Decision
- **GTM:** той самий контейнер, стандартний сніпет у `<head>` + `<noscript>` після `<body>`, як рекомендує Google. Порядок завантаження не змінюємо, щоб не зламати теги команди реклами. Подія `form_submit` (ADR-0004) — єдина нова точка контакту.
- **Hotjar:** той самий сніпет, як є.
- **Карта:** той самий embed, `loading="lazy"`, з `title` для доступності. Варіант «статичне превʼю → карта за кліком» — опція (SPEC §11 п.5).
- Partytown (винесення скриптів у web worker) **не використовуємо**: GTM-теги реклами (пікселі, конверсії) у ньому часто ламаються, а перевірити їх ми не можемо — контейнер не наш.

## Options Considered (карта)
| | Lazy iframe (обрано за замовч.) | Превʼю + клік | Maps JavaScript API |
|---|---|---|---|
| Як зараз виглядає | так | статичне зображення до кліку | повний контроль стилю |
| Вага до взаємодії | iframe вантажиться при скролі до нього | майже 0 | API-скрипт |
| Прибрати зайві елементи UI | ні (embed не налаштовується) | частково (до кліку) | так |
| Потрібен API-ключ / білінг Google | ні | ні | так |

## Consequences
- Аналітика продовжує працювати без змін у GTM, крім тригера на `form_submit`.

## Risks
- GTM і Hotjar — основні «важкі» скрипти, вплинуть на швидкість. Ми їх не контролюємо; фіксуємо їхній внесок у звіті QA (етап 7).
- Без доступу до контейнера не знаємо всіх тегів; перевіряємо на preview з вимкненим блокувальником, що теги спрацьовують так само, як на живому сайті.
